🆘 TROUBLESHOOTING:
════════════════════════════════════════════════════════════════════════════════

If deployment fails:

1. Check GitHub Actions logs (red X)
2. Look for error messages
3. Common issues:

   ❌ "InvalidCredentials"
      → Check AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY
      → Re-run workflow

   ❌ "SSH key invalid"
      → Check SSH_PRIVATE_KEY has -----BEGIN/END----- lines
      → No extra spaces

   ❌ "Connection refused"
      → Wait 2-3 minutes for EC2 to start
      → Re-run workflow

   ❌ "Ansible failed"
      → Check GitHub repo URL is correct
      → Verify SSH key format

Re-run workflow:
  GitHub Actions → Failed run → "Re-run all jobs" button
