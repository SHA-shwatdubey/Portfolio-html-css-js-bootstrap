🔑 5 CREDENTIALS NEEDED
════════════════════════════════════════════════════════════════════════════════

From AWS:
  1. AWS_ACCESS_KEY_ID        (Format: AKIA...)
  2. AWS_SECRET_ACCESS_KEY    (Format: Long random string)

From Your Machine:
  3. SSH_PRIVATE_KEY          (Generate: ssh-keygen -t rsa -b 4096 ...)
  4. SSH_PUBLIC_KEY           (Same generation command)

Configuration:
  5. AWS_REGION               (Example: us-east-1)
  6. GITHUB_REPO_URL          (Example: https://github.com/user/repo.git)

See: CREDENTIALS_SETUP.md for detailed step-by-step instructions


🚀 3 WAYS TO DEPLOY
════════════════════════════════════════════════════════════════════════════════

METHOD 1: ONE-COMMAND DEPLOY (EASIEST) ⭐ RECOMMENDED
────────────────────────────────────────────────────
$ chmod +x deploy.sh
$ ./deploy.sh

Features:
  • Checks prerequisites
  • Asks for credentials interactively
  • Creates everything automatically
  • Configures Terraform, runs Ansible
  • Shows website URL when done

Time: ~15 minutes
Best for: First-time deployment, beginners


METHOD 2: GITHUB ACTIONS (FULLY AUTOMATED) ⭐ SMART
──────────────────────────────────────────────────
1. Add 5 GitHub Secrets (AWS creds + SSH key)
2. Update terraform.tfvars with your values
3. git push origin main
4. Watch GitHub Actions tab
5. Website auto-deploys!

Time: ~15 minutes (first), then automatic on every push
Best for: Ongoing development, CI/CD workflow


METHOD 3: MANUAL DEPLOYMENT (FOR LEARNING)
──────────────────────────────────────────
$ aws configure                          # Configure AWS
$ cd terraform
$ terraform init                         # Initialize
$ terraform plan -var-file=terraform.tfvars
$ terraform apply -var-file=terraform.tfvars

$ cd ../ansible
$ ansible-playbook -i hosts.ini deploy.yml

Time: ~20 minutes
Best for: Understanding each component, customization
